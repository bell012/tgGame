# 体育首页

`index.vue` 根据现有 `useIsMobile()` 选择 PC / H5 布局。两端只创建一份
`useSportsPage()`，共用选择、收藏、金额和串关计算；此页面的赛事与提交均为本地模拟，
不请求真实赛事、投注或钱包写接口。

## H5 接入边界

- `SportsH5Page.vue`：球种事件接入、实时卡外壳、联赛分组与整组展开/收起。
- `SportsMatchCardH5.vue`：赛事信息、收藏、阶段比分；盘口使用 `MatchOdds` 公开入口。
- `SportsBetSlipH5.vue` 与 `h5-bet.ts`：底部投注单、数字键盘、快捷金额与模拟提交。
- `h5-data.ts`：七球种、21 联赛、84 场模拟赛事；同一 ID 始终映射到同一赛事。
- 不包含赛事详情路由、真实视频或动画播放器。

原组件从各自 `index.vue` 接入，不覆盖其内部样式或修改协议。当前日期分类、搜索筛选、
实时卡横排赔率尚未提供可用的 H5 协议，页面预留槽位；不通过自制按钮替代组件。
现有 H5 盘口只展示 `option.label`，因此页面按 H5 格式派生标签，选择事件仍通过
`market.id` / `option.id` 回查原始数据，避免盘口线重复进入投注单。

## 投注单交互

- 点击有效赔率选项立即打开；同场更换选项采用替换，再点同一选项取消。
- 使用现有 `popShell` 的 `bottom-sheet` 动画与共享 `usePageScrollLock()`。
- 关闭遮罩保留选项和金额；首页不显示悬浮入口，点击赔率时弹出投注单。
- `Add to Parlay` 切换串关并收起，即使仅选一场也允许继续加场；不足两场不能提交。
- `Add Event` 收起以继续选择，下一次选赔率时重新打开。
- 单关首次打开默认展开自定义键盘，不调用系统数字键盘。
- 快捷金额行可横向滑动至 `Edit`，从底部打开独立编辑层；可修改、长按拖动排序，
  键盘上下方向键也可排序。保存后更新快捷金额，关闭编辑层则放弃草稿。
- 金额框与描边按钮在本地组件中显式声明实线边框，避免全局按钮重置覆盖边框样式。
- 所有金额与币种展示复用项目工具；模拟余额为 1000，H5 单项限额为 5.00–311.11。
- 提交中、成功和失败都是本地状态，不生成真实订单、不扣减真实余额。

## 本地验证样例

每个球种的第三联赛中，第一场滚球标记为 `closed`，第二场滚球标记为 `fail`。
从正常卡片入口选择即可验证闭盘提示和提交失败；其余赛事可验证成功流程。
输入 1 或 500 可分别验证最低/最高金额提示；增加串关组合可验证总额超出余额。
页面不提供额外调试或预览控制面板。

PC 的原组件、网格布局和分页保持独立，不将 H5 限额、键盘或弹层策略应用到 PC。
