# Lucky Spin 公共组件使用文档

## 1. 模块定位

`src/components/common/lucky-spin` 是 **Lucky Spin 活动页的 UI 组件层**，负责展示型 UI 与通用类型，不包含：

- 接口请求 / Mock 逻辑（见 `src/api/modules/promotion.ts`）
- 转盘 canvas 实现（见 `src/views/activity/lucky-spin/components/LuckySpinWheel.vue`）
- 任务提醒弹窗（见 `src/views/activity/lucky-spin/components/dialogs/LuckySpinReminderPopup.vue`）

弹窗级组装参考：`src/views/activity/lucky-spin/LuckySpinModal.vue`，入口 `openLuckySpin()`。

统一入口：

```ts
import {
  LuckySpinHeroHeader,
  LuckySpinWinnerTicker,
  LuckySpinVoucherSelector,
  LuckySpinResultPopup,
  LuckySpinVoucherCard,
  LUCKY_SPIN_TOKENS,
  LUCKY_SPIN_ASSETS,
  type LuckySpinInfoResult,
  type LuckySpinResultVariant
} from '@/components/common/lucky-spin'
```

## 2. 组件关系

```text
LuckySpinHeroHeader          标题 + 副标题 + 倒计时
        ↓
[LuckySpinWheel]             页面级组件，不在本目录
        ↓
LuckySpinWinnerTicker        中奖滚动条
        ↓
LuckySpinVoucherSelector     底部票券游戏切换
        ↓
LuckySpinResultPopup         抽奖结果弹窗
  └─ LuckySpinVoucherCard    票券卡片（Popup 内部使用，也可单独用）
```

## 4. 组件 API

### 4.1 LuckySpinHeroHeader

顶部标题区：渐变标题、最高奖金副标题、活动倒计时。

**Props**

| 属性           | 类型     | 默认值                             | 说明                                             |
| -------------- | -------- | ---------------------------------- | ------------------------------------------------ |
| `title`        | `string` | i18n `luckySpinPage.title`         | 主标题                                           |
| `subtitle`     | `string` | i18n `luckySpinPage.subtitle`      | 副标题，可用 `{amount}`                          |
| `maxPrizeText` | `string` | `'₱888'`                           | 传入 subtitle 的 `{amount}`                      |
| `endTime`      | `number` | —                                  | 活动结束时间，**毫秒时间戳**；不传则不显示倒计时 |
| `expiresLabel` | `string` | i18n `luckySpinPage.spinExpiresIn` | 倒计时下方说明文案                               |

**Events**：无

**示例**

```vue
<LuckySpinHeroHeader :max-prize-text="spinInfo.maxPrizeText" :end-time="spinInfo.endTime" />
```

---

### 4.2 LuckySpinWinnerTicker

横向滚动展示近期中奖用户。

**Props**

| 属性    | 类型                 | 默认值 | 说明                           |
| ------- | -------------------- | ------ | ------------------------------ |
| `items` | `WinnerTickerItem[]` | —      | 中奖记录列表                   |
| `speed` | `number`             | `40`   | 预留参数，当前用于计算动画时长 |

**Events**：无

**行为说明**

- `items` 为空时不渲染
- 列表较短时会复制多份以保证滚动连贯
- 无头像时显示用户名首字母

**示例**

```vue
<LuckySpinWinnerTicker :items="spinInfo.winnerRecords" />
```

---

### 4.3 LuckySpinVoucherSelector

底部票券游戏图标轮播 + 票券数量入口。

**Props**

| 属性            | 类型                | 说明                  |
| --------------- | ------------------- | --------------------- |
| `items`         | `VoucherGameItem[]` | 可切换的游戏/活动列表 |
| `activeIndex`   | `number`            | 当前高亮项索引        |
| `totalVouchers` | `number`            | 用户持有票券总数      |

**Events**

| 事件                 | 参数              | 说明                          |
| -------------------- | ----------------- | ----------------------------- |
| `@select`            | `(index: number)` | 点击某个游戏图标              |
| `@prev`              | —                 | 左箭头，窗口向前滚动          |
| `@next`              | —                 | 右箭头，窗口向后滚动          |
| `@open-voucher-list` | —                 | 点击「You have N Vouchers ›」 |

**行为说明**

- 可视区域最多展示 5 个图标，选中项自动滚入视口
- 图标优先用 `item.icon`，否则按 `item.id` 从 `getGameIcon` 取本地资源

**示例**

```vue
<LuckySpinVoucherSelector
  :items="spinInfo.voucherGames"
  :active-index="activeGameIndex"
  :total-vouchers="spinInfo.totalVouchers"
  @select="handleGameSelect"
  @prev="handleGamePrev"
  @next="handleGameNext"
  @open-voucher-list="showReminder = true"
/>
```

### 4.4 LuckySpinResultPopup

抽奖结果弹窗，支持现金 / 再转 / 未中奖 / 票券等样式。

**Props**

| 属性             | 类型                         | 默认值               | 说明                               |
| ---------------- | ---------------------------- | -------------------- | ---------------------------------- |
| `visible`        | `boolean`                    | —                    | 是否显示（支持 `v-model:visible`） |
| `variant`        | `LuckySpinResultVariant`     | —                    | 结果类型，见下方                   |
| `title`          | `string`                     | 按 variant 自动 i18n | 弹窗标题                           |
| `highlightText`  | `string`                     | —                    | 高亮金额/文案（非票券样式）        |
| `subtext`        | `string`                     | 按 variant 自动 i18n | 副文案                             |
| `heroImage`      | `string`                     | 按 variant 取内置图  | 中部插图 URL                       |
| `buttonText`     | `string`                     | 按 variant 自动 i18n | 主按钮文案                         |
| `voucherCount`   | `number`                     | `0`                  | 票券数量（票券样式副文案）         |
| `vouchers`       | `LuckySpinVoucherCardData[]` | `[]`                 | 票券列表（`voucher_*` 样式）       |
| `closeOnOverlay` | `boolean`                    | `true`               | 点击蒙层是否关闭                   |

**`variant` 取值**

| 值               | UI 形态                   |
| ---------------- | ------------------------- |
| `cash`           | 现金中奖：大图 + 高亮金额 |
| `spin_again`     | 再转一次                  |
| `no_prize`       | 未中奖                    |
| `voucher_single` | 单张票券                  |
| `voucher_multi`  | 多张票券列表              |

**Events**

| 事件              | 说明                    |
| ----------------- | ----------------------- |
| `@update:visible` | 关闭时同步 `visible`    |
| `@confirm`        | 非票券样式点击主按钮    |
| `@use-now`        | 票券样式点击「Use Now」 |
| `@close`          | 任意方式关闭            |

**示例**

```vue
<LuckySpinResultPopup
  v-model:visible="showResult"
  :variant="resultVariant"
  :highlight-text="resultHighlight"
  :vouchers="resultVouchers"
  :voucher-count="resultVouchers.length"
/>
```

### 4.5 LuckySpinVoucherCard

单张活动票券卡片，常用于结果弹窗列表。

**Props**

| 属性   | 类型                       | 说明     |
| ------ | -------------------------- | -------- |
| `data` | `LuckySpinVoucherCardData` | 票券数据 |

**Events**：无

**行为说明**

- 背景色：`data.bgColor` 或按 `data.type` 查 `getVoucherCardBg`
- 图标：`data.icon` 或按 `data.type` 查 `getGameIcon`
- 文案颜色：按 `data.type` 查 `getVoucherCardTextColors`

**示例**

```vue
<LuckySpinVoucherCard :data="voucher" />
```

## 5. 类型定义

```ts
/** 结果弹窗样式 */
type LuckySpinResultVariant =
  | 'cash'
  | 'spin_again'
  | 'no_prize'
  | 'voucher_single'
  | 'voucher_multi'

/** 转盘格奖品类型 */
type PrizeType = 'cash' | 'spin_again' | 'no_prize' | 'voucher'

/** 滚动条单项 */
interface WinnerTickerItem {
  id: string
  avatar: string // 头像 URL，空则显示首字母
  username: string
  prizeText: string // 如 "₱188"
}

/** 底部游戏切换项 */
interface VoucherGameItem {
  id: string // 如 golden_egg / lucky_spin，用于 getGameIcon
  icon?: string
  label?: string
  route?: string // 业务层自行处理跳转
}

/** 票券卡片 */
interface LuckySpinVoucherCardData {
  id: string
  type: VoucherCardType // golden_egg | lucky_spin | cash_voucher 等
  title: string
  rewardText: string
  expiresAt: string // 展示用过期时间字符串
  bgColor?: string
  icon?: string
}

/** 转盘格奖品（传给 Wheel 组件） */
interface LuckySpinPrize {
  index: number
  type: PrizeType
  label: string // 格位文案，后端配置
  icon: string // 格位 icon URL，后端配置
  amount?: number
  voucherType?: VoucherCardType
}

/** 活动页接口聚合结构（供页面 state 使用） */
interface LuckySpinInfoResult {
  endTime: number
  maxPrizeText: string
  remainingSpins: number
  totalVouchers: number
  prizes: LuckySpinPrize[]
  tasks: LuckySpinTask[]
  recentVouchers: LuckySpinVoucherCardData[]
  winnerRecords: WinnerTickerItem[]
  voucherGames: VoucherGameItem[]
  rules: string[]
}

/** 单次抽奖结果 */
interface LuckySpinResult {
  prizeIndex: number
  prize: LuckySpinPrize
  vouchers?: LuckySpinVoucherCardData[]
}
```

## 6. 常量与工具

### 6.1 LUCKY_SPIN_TOKENS

设计 token，页面背景、倒计时样式、转盘尺寸等。页面容器示例：

```vue
<div :class="LUCKY_SPIN_TOKENS.modalMaskClass">
```

常用字段：`modalMaskClass`、`modalBlur`、`titleGradient`、`countdownBox`、`activeBorder`、`activeGlow`。

### 6.2 LUCKY_SPIN_ASSETS

静态图片资源映射：

- `wheel.*` — 转盘外框、指针、扇区、阴影
- `modals.*` — 结果弹窗插图
- `vouchers.games.*` — 底部游戏 icon

### 6.3 工具函数

| 函数                             | 说明                                             |
| -------------------------------- | ------------------------------------------------ |
| `getGameIcon(id)`                | 按游戏 id 取本地 icon，未知 id 回退 `lucky_spin` |
| `getPrizeIcon(prize)`            | 返回 `prize.icon`，转盘格 icon 由后端提供        |
| `getVoucherCardBg(type)`         | 票券卡片背景渐变                                 |
| `getVoucherCardTextColors(type)` | 票券卡片文字色                                   |
| `RESULT_HERO_IMAGES`             | 现金/再转/未中奖弹窗默认插图                     |
| `WHEEL_SEGMENT_COUNT`            | 转盘格数，固定 `8`                               |

## 7. 页面组装示例

精简版（不含 Wheel、Reminder、接口逻辑）：

```vue
<template>
  <div :class="LUCKY_SPIN_TOKENS.modalMaskClass">
    <LuckySpinHeroHeader :max-prize-text="spinInfo.maxPrizeText" :end-time="spinInfo.endTime" />

    <!-- LuckySpinWheel：views/activity/lucky-spin 页面级组件 -->
    <LuckySpinWheel
      :prizes="spinInfo.prizes"
      :disabled="spinInfo.remainingSpins <= 0"
      @go="handleSpin"
      @spin-end="handleSpinEnd"
    />

    <LuckySpinWinnerTicker :items="spinInfo.winnerRecords" />

    <LuckySpinVoucherSelector
      :items="spinInfo.voucherGames"
      :active-index="activeIndex"
      :total-vouchers="spinInfo.totalVouchers"
      @select="activeIndex = $event"
      @open-voucher-list="showReminder = true"
    />

    <LuckySpinResultPopup v-model:visible="showResult" variant="cash" highlight-text="₱50" />
  </div>
</template>

<script setup lang="ts">
import {
  LuckySpinHeroHeader,
  LuckySpinWinnerTicker,
  LuckySpinVoucherSelector,
  LuckySpinResultPopup,
  LUCKY_SPIN_TOKENS,
  type LuckySpinInfoResult
} from '@/components/common/lucky-spin'
import LuckySpinWheel from '@/views/activity/lucky-spin/components/LuckySpinWheel.vue'
import { ref } from 'vue'

const spinInfo = ref<LuckySpinInfoResult>(/* 接口数据 */)
const activeIndex = ref(0)
const showResult = ref(false)
</script>
```

**`variant` 与页面 state 映射建议**

| 抽奖结果 `prize.type` | `variant`        | `highlightText`  |
| --------------------- | ---------------- | ---------------- |
| `cash`                | `cash`           | `prize.label`    |
| `spin_again`          | `spin_again`     | i18n 文案        |
| `no_prize`            | `no_prize`       | i18n 文案        |
| `voucher`（1 张）     | `voucher_single` | —，传 `vouchers` |
| `voucher`（多张）     | `voucher_multi`  | —，传 `vouchers` |

## 8. i18n 依赖

组件内置文案来自 `luckySpinPage` 命名空间，需保证 `en.json` / `zh.json` 已配置：

| Key                                  | 使用位置                        |
| ------------------------------------ | ------------------------------- |
| `luckySpinPage.title`                | HeroHeader 主标题               |
| `luckySpinPage.subtitle`             | HeroHeader 副标题（`{amount}`） |
| `luckySpinPage.spinExpiresIn`        | HeroHeader 倒计时说明           |
| `luckySpinPage.won`                  | WinnerTicker                    |
| `luckySpinPage.youHave` / `vouchers` | VoucherSelector                 |
| `luckySpinPage.prev` / `next`        | VoucherSelector 箭头            |
| `luckySpinPage.expiresOn`            | VoucherCard                     |
| `luckySpinPage.result.*`             | ResultPopup 各 variant 默认文案 |

自定义文案时，通过组件 Props（如 `title`、`subtitle`、`buttonText`）覆盖即可，无需改 i18n。

## 9. 注意事项

1. **`endTime` 为毫秒时间戳**，HeroHeader 内部每秒刷新剩余时间。
2. **ResultPopup 使用 `Teleport to="body"`**，注意 z-index（`10020+`）与全局弹窗栈。
3. **转盘格 icon** 由后端 `prizes[].icon` 下发，公共层不提供默认奖品图。
4. **票券 type** 已知：`golden_egg`、`lucky_spin`、`cash_voucher`、`lucky_red_envelope`、`mystery_box`；未知 type 会使用灰色默认样式。
5. **Wheel / Reminder 不在本目录**，扩展转盘逻辑或任务规则请改 `src/views/activity/lucky-spin/`。

## 10. 接入建议

- 新页面优先从 `@/components/common/lucky-spin` 按需引入，避免复制 UI 片段。
- 业务状态（loading、spinning、接口）放在 modal composable（参考 `useLuckySpinModal.ts`）。
- 仅调整视觉 token 时改 `design-tokens.ts`；换图改 `assets.ts` 与 `src/static/img/lucky-spin/`。
